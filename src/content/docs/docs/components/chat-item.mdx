## Chat Item (`<tg-chat-item>`)

A component used to display a single dialogue item in a chat list, complete with an avatar, user name, message preview, and timestamp.

## Usage

Copy the following code into your Astro page or layout:

```astro
---
import ChatItem from "../components/ChatItem.astro";
---

<ChatItem
  name="John Doe"
  message="Hello world!"
  time="15:30"
/>
```
