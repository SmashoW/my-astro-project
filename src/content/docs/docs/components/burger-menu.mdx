## Burger Menu (`<tg-burger-menu>`)

A component used to display an interactive mobile menu button. It utilizes a custom HTML element (Web Component) and an icon from the `@lucide/astro` package.

## Live Preview

You can interact with the live component directly inside the Starlight documentation:

<div class="not-content">
  <BurgerMenu />
</div>

## Usage

Copy the following HTML structure into your template:

```astro
---
import BurgerMenu from "../components/BurgerMenu.astro";
---

<BurgerMenu />
```
